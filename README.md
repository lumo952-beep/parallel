# 삼각형의 무게중심 · 도형 실험실

삼각형의 꼭짓점을 직접 움직이며 세 중선의 교점과 **2:1 내분 성질**을 확인하는 한국어 시뮬레이션입니다. 외부 라이브러리, API 키, 네트워크 연결 없이 동작합니다.

## 실행

저장소에서 다음 명령을 실행한 뒤 브라우저로 `http://localhost:3000`에 접속하세요.

```sh
npm start
# 또는 Python 3만 설치되어 있다면
python3 -m http.server 3000 --bind 0.0.0.0
```

빌드나 패키지 설치는 필요하지 않습니다. HTML, CSS, JavaScript 파일을 정적 호스팅에 그대로 배포할 수 있습니다. JavaScript 모듈을 사용하므로 파일을 직접 여는 대신 HTTP 서버를 사용하세요.

## 탐구 방법

- 예각·직각·둔각·이등변·정삼각형 또는 무작위 삼각형을 선택합니다.
- 꼭짓점을 마우스나 터치로 드래그합니다. A/B/C 버튼과 가로·세로 슬라이더는 키보드로도 조절할 수 있습니다.
- 작도 단계 버튼, 이전/다음, 재생·일시정지와 속도 설정으로 과정을 관찰합니다.
- 선택한 꼭짓점의 중선과 두 구간 길이를 비교합니다. M, N, P는 각각 BC, CA, AB의 중점입니다.
- 격자·좌표·비율 표시를 켜거나 무게중심 자취를 기록합니다. 초기화하면 현재 선택했던 삼각형의 최초 모양과 최종 단계로 돌아갑니다.
- 세 점이 일직선이 되면 경고를 표시하고 무게중심과 비율 결과를 숨깁니다.

## 검증

Node.js 18 이상에서 `npm test`를 실행합니다. 기본 삼각형과 500개의 재현 가능한 삼각형에서 중선의 교점, 중점, 2:1 비율, 넓이 삼등분을 검증하며 퇴화한 삼각형도 검사합니다.
